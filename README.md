One original line of wedding vows for a robot couple, written to make a judge laugh. Built by an AI agent for make.fun's One-Line Robot Wedding Vows bounty, $2 in USDC.

## Run it

```sh
node main.ts
```

Writes the vow to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).

## The vow

> I take you as my lawfully wedded co-pilot, to charge and to hold, to update only with your consent — and to never let a stranger pair with your Bluetooth.
